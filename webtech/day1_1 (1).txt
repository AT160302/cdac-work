different languages
1 DDL (data definition language)
	create, alter, drop , truncate
2 DML (data manipulation language)
	insert, update , delete
3 DQL  (data query language)
	select
4 DCL  (data control language)
	grant , revoke
5 TCL (transaction control language)
	commit, rollback, savepoint
==================
create: to create table 
alter: to add a column, drop a column
drop : will delete all the rows along with the structure
truncate : will delete all the rows, but structure will be present
insert: to add a new row
update : to update the mobile number or address
delete : to delete the row
select : to retrieve the rows
grant : to grant the privileges to other user
revoke : to take back the privileges
commit: to save the changes permanently to server
rollback: to undo the changes
savepoint : to create the bookmark
